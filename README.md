Dataset is from the [Full TMDB Movies Dataset 2024 (1M Movies) by Asaniczka on Kaggle](https://www.kaggle.com/datasets/asaniczka/tmdb-movies-dataset-2023-930k-movies)

To download the data, run src/download_data.py. This will save it in data/raw. To clean the data, run src/clean_data.py. This will save it in data/clean.
